LogMem Product Plan

LogMem is the public product name. LogMem is built on the ACMI protocol. ACMI is the internal protocol name. The commercial plan has two parts. One part is the open protocol. The other part is a paid cloud layer. The model is the same as Next.js with Vercel, Postgres with Supabase, and MCP with Anthropic.

The Pitch

LogMem is the coordination product for AI agent fleets. LogMem is built on the ACMI protocol. The protocol uses three Redis keys. The keys are Profile, Signals, and Timeline. These keys replace 800 lines of agent memory code. Core operations do not use a vector database. Core operations do not use a knowledge graph. Core operations do not call an LLM. A read completes in under 5 ms. LogMem works with any model. LogMem works with every agent framework.

User Personas

🛠️ Indie AI Builder

Who: A solo developer builds multi-agent tools. The developer uses Claude Code, Cursor, or a similar tool.

Pain: Agents lose context between sessions. The developer has no low-cost way to coordinate 2 to 5 agents.

Value: The free tier covers this fleet. Setup takes about 10 minutes. LogMem is MCP-native.

🏢 Startup CTO

Who: The CTO leads an AI team of 5 to 20 people. The team builds autonomous agent products.

Pain: Agent coordination fails at a larger scale. The team has no observability. Agents do duplicate work.

Value: The lock protocol stops conflicts. The fleet dashboard shows the full fleet.

🔬 Research Lab

Who: A research team studies multi-agent systems. The team can be academic or corporate.

Pain: The team needs a coordination baseline that other teams can repeat.

Value: The license is MIT. The audit trail is event-sourced. The design supports benchmarks.

Competitive Moat

  • Fleet primitives. The set includes the Lock Protocol, anti-dead heartbeats, and an RL cycle. No other memory system ships this set.
  • Node.js first. Most competitors are Python only. LogMem targets the JavaScript and TypeScript gap. LogMem is built on the ACMI protocol.
  • Redis-native design. The core path does not use SQL. A read completes in under 5 ms. Core reads do not depend on an LLM.
  • MCP-native. LogMem works with every MCP-compatible tool. MCP is a growing standard.
  • Brand. LogMem is the public product name. ACMI is the internal protocol name. The brand idea is Agent Context Engineering.
