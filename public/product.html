LogMem Product Plan

LogMem is the public product name. It is built on the ACMI protocol. ACMI is only the internal protocol name. The open-source release is free under the MIT license. Paid work is an audit, a done-for-you build, a monthly retainer, or a dedicated stack for one client on Elestio.

The Pitch

LogMem coordinates fleets of AI agents. LogMem is built on the ACMI protocol. The protocol keeps state in three Redis keys: Profile, Signals, and Timeline. These keys replace 800 lines of agent memory code. A custom LogMem deployment uses Qdrant. Core operations do not use a knowledge graph. Core operations do not call an LLM. A read completes in under 5 ms. LogMem works with any model, and it works with every agent framework.

User Personas

🛠️ Indie AI Builder

Who: A solo developer who builds multi-agent tools with Claude Code, Cursor, or a similar tool.

Pain: Agents lose context between sessions. Coordinating 2 to 5 agents is hard to do at a low cost.

Value: The free open-source release covers this fleet. Setup takes about 10 minutes. LogMem speaks MCP.

🏢 Startup CTO

Who: A CTO who leads an AI team of 5 to 20 people and ships autonomous agent products.

Pain: Coordination breaks as the fleet grows. The team cannot see what agents are doing, and agents repeat the same work.

Value: The lock protocol stops conflicts. The fleet dashboard shows the whole fleet.

🔬 Research Lab

Who: An academic or corporate team that studies multi-agent systems.

Pain: The team needs a coordination baseline that another team can repeat.

Value: The license is MIT. The audit trail is a log of events. The design is easy to benchmark.

Competitive Moat

  • Fleet primitives. LogMem ships the Lock Protocol, anti-dead heartbeats, and an RL cycle. No other memory system ships this set.
  • Node.js first. Most competitors are Python only. LogMem targets the JavaScript and TypeScript gap. LogMem is built on the ACMI protocol.
  • Redis keys, plus Qdrant on custom deployments. The core path does not use SQL. A read completes in under 5 ms. Core reads do not depend on an LLM. A custom deployment uses Qdrant.
  • MCP. LogMem works with every MCP-compatible tool. MCP is a growing standard.
  • Names. LogMem is the public product name. ACMI is only the internal protocol name. The brand idea is Agent Context Engineering.
