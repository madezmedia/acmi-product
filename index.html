LogMem.
Three keys. That is the whole protocol.

LogMem gives AI agents persistent context. It is built on the ACMI protocol. The core uses Redis only. Qdrant is used on custom or dedicated deployments. Core operations do not use a knowledge graph. Core operations do not call an LLM.

N° 01 How it works

Three keys per entity. That is the whole protocol.

P Profile — who
acmi:{ns}:{id}:profile

Hard state snapshot — name, stage, budget, specs. Written by explicit updates.

S Signals — now
acmi:{ns}:{id}:signals

AI-synthesized soft state — churn risk, sentiment, next best action. Updated by agents.

T Timeline — then
acmi:{ns}:{id}:timeline

Chronological event stream (Redis ZSET). Merges events from every platform into one story.

N° 02 Quick Start

Get running in 30 seconds.

# 1. Set your Upstash Redis credentials
export UPSTASH_REDIS_REST_URL="https://your-endpoint.upstash.io"
export UPSTASH_REDIS_REST_TOKEN="your-token"

# 2. Write a profile
node acmi.mjs profile sales acme-corp '{"contact":"Jane","stage":"proposal","value":50000}'

# 3. Log an event
node acmi.mjs event sales acme-corp email "Sent proposal PDF"

# 4. Update signals
node acmi.mjs signal sales acme-corp '{"sentiment":"positive","next_action":"Follow up Friday"}'

# 5. Read everything back
node acmi.mjs get sales acme-corp
